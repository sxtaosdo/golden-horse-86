# r02 · 手机像素素材生产

状态：产品方向已接受；144帧马匹、12类道具及地面材质已接入本地Creator，验收见[手机运行记录](../../../../tests/MOBILE_R02.md)。未晋级P0001共享Canon。

使用内置image_gen生成，延续Owner批准的[r01白马/红衣骑手](../r01/README.md)。`generated/`保留全部原始RGBA图；`production-complete.json`保存18张马匹图和道具图的完整提示词与默认生成路径。未从参考视频提取运行素材。

- 六种马色：白、洋红、朱红、钴蓝、金黄、翠绿。
- 每种包含侧面向右、斜前、正面三张1536×1024图集；每图4列×2行，八个不同步态，共144帧。
- 运行时由SpriteFrame矩形读取原图；脚点及侧面鼻尖元数据在manifest中。向左镜像图像，独立绘制正向号码。像素方向切换保持完全不透明，避免双轮廓。
- scenery.png包含植物、花坛、围栏、闸门、发令员、距离牌、电子牌、补给棚、货车、货箱、树木、观众。道具图采用人工核对的独立矩形，不假设统一网格。
- ground.png为泥地/草地两块材质，提示要求严格正交俯视；游戏以同一U形道路Mask裁切泥地。

选用原图与元数据位于[art/final/gameplay/r02](../../../final/gameplay/r02/)，运行副本由Cocos-MCP导入`assets/resources/race`，禁止手改.meta/.scene/.prefab。白马运行文件使用`-r02`后缀以避开首次会话中断遗留的导入缓存；原始图字节不变。

原版只作玩法和视觉参考；本轮不宣称像素逐点一致、原机赔率算法或原版音轨完成。
