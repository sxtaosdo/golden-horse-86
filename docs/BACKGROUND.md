## 定位

候选产品名：《霓虹荒野：黄金赛马》。世界内赛事名：“驿站杯”。“86”保留为经典玩法模式标签；当前工程名不因本文改变。

这是一款发生在《霓虹荒野》世界里的轻量赛马预测游戏。玩家是停留在补给驿站的普通旅人，通过赛事终端为自己看好的冠亚军组合分配赛事积分，观看六匹马比赛，并领取命中组合的积分奖励。

## 背景正文

荒野航路与地面运输线之间，散布着供旅人休息、商队补给和车辆维修的驿站。技术仍然先进，但零件、能源和可靠的服务并不总是齐备。赶路的人需要等待，也需要一点与生存无关的热闹。

这座驿站把附近一块旧训练场修成了赛场。商队停靠较多的日子，驯养员带来六匹受过训练的赛马，维修工检查闸门与计时器，小摊在围栏外开张。短暂的“驿站杯”成为居民与过路人的共同消遣。

玩家没有特殊身份：可能刚交完一批货，也可能只是等下一班车。选好组合，看六匹马从闸门冲出，绕过唯一的弯道，沿返程直道争夺前两名。一场比赛结束，赢了便多一份喝彩，没猜中也可以等下一场；驿站的生活照常继续。

## 与现有玩法的对应

| 游戏对象 | 背景解释 | 本轮边界 |
|---|---|---|
| 玩家 | 候车或补给期间的普通旅人 | 不预设主线角色、阵营或救世主身份 |
| 六匹马 | 本地驯养队带来的六匹赛马 | 保留六种辨识色与号码；不新增物种、超能力或改造设定 |
| 组合押分与倍率 | 赛事终端中的名次预测和对应积分奖励 | 继续现有前二组合机制；赔率仍以待校对的游戏配置为准 |
| 积分 | 活动内使用的赛事积分 | 不关联跨产品货币、食材、水或能源；本作已有虚拟积分范围不扩大 |
| 一条弯道 | 旧训练场改成的短程折返赛道 | 对应已确认的直道→唯一弯道→反向直道 |
| 历史结果 | 驿站赛事公告栏 | 显示近几场组合和倍率，不附加离线世界模拟 |
| 连续多局 | 同一天的多场短赛 | 不自动推进年代、商路归属或地区大事件 |

## 场景内容建议

比赛区域可以看见修补过的围栏、反复维护的闸门、可靠但略显老旧的电子计时牌；围栏外是补给棚、货箱、停靠车辆与观赛小摊。短赛场的日常热闹与远处仍在运转的运输生活形成联系。

整体情绪是“资源并不充裕，但人们仍愿意认真办一场比赛”。世界观气质来自日常生计、维修和贸易，不给小型休闲玩法附加战争主线或强制生存惩罚。

这是场景内容提案，不是新美术规范。本文没有出图、替换现有美术或改变2D玩法镜头；后续视觉制作按P0001主风格及明确开放的产品范围执行，先核对实际参考。不得因“废土”二字自行改成通篇灰暗写实。
