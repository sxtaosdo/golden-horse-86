# 原版赛程节奏校对

状态：Accepted；Owner当前用户，2026-10-24。依据用户对起跑直道、弯道和出弯直道加速的反馈，调整现有比赛演出，保持已确认的近景、单弯路线、抽序、赔率和返分。

本轮重新取得并抽帧核对docs/RESEARCH.md中的搜狐86版实录（283.157秒、960×540、30fps）；主要观察24～49秒、72～97秒两局。出闸后的约1～2秒速度逐步建立，直道马群有相对超越；弯道转向占用独立节奏，出弯后恢复侧向并继续提速。录像有字幕遮挡和视点运动，不能把屏幕位移直接当成原机世界速度，也不据此声明已还原原机公式。

本轮用连续距离曲线替代统一匀速时间：起步从零速度建立、首直道提速后进入弯道节奏、出弯较低速度衔接再逐渐冲刺。共享镜头沿同一曲线走；每马最终直道保持原定完成时刻，出弯与冲线速度连续。步态时钟由经过时间与实际路程共同驱动，速度变化时帧频连续变化，表现层不另存玩法速度。

原型首马24秒、相邻完成间隔0.35秒继续作为演出参数，准备3秒不计入跑程。具体曲线系本产品拟合，不宣称原版精确值；验收记录随后登记于tests/RACE_PACE.md。
