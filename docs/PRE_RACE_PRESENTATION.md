# 赛前演出与随机广角

状态：Accepted。Owner当前用户于2026-10-24批准完整方案并要求实施；本地实现与运行验证完成，未发布。Runtime证据及听感未验限制见[验收记录](../tests/PRE_RACE.md)。

每场独立表现随机选择正中(.72倍)、左侧(-32世界单位、.76倍)、上方归位(+24x/-12y、.78倍)三种广角，不连续重复；倍率相对于当前手机近景，不是绝对scale。同场押分保持镜头稳定，切赛事不重抽。准备3秒的前2秒smoothstep收至原近景，最后1秒稳定；开跑接原跟随，下一场回新的广角。镜头不改变下注区/HUD，所有投影读取最终同一取景。resize重算尺寸但保留当轮选择。

新增6马各10帧独立待机/准备侧视素材与6帧旗手素材；马匹保留足点、配色及号码。普通呼吸/缰绳/尾部动作错峰，偶尔低头与前蹄小动作；准备停止随意动作，剩2秒时骑手压低。旗手押分低旗微动、准备举旗、开跑落旗。各阶段使用模型round/phase/preparationRemaining，不复制比赛状态或倒数。

成功加注后对应两马号码提亮.35秒，格子轻压回弹，不堆叠Tween；撤销/清空沿用原反馈。地区/冠军赛设备相机赛前扫视，比赛重新跟随真实领跑者；冠军大屏含场次、参赛号码与准备倒数。原144帧奔跑素材、比赛节奏、排名RNG、赔率、返分与起点七栏遮挡保持。

使用独立表现随机源，不消费模型Math.random；纯表现控制器持有镜头选择、待机时钟、反馈寿命与阶段边沿。新增环境底音、蹄点、门锁、倒数、广播电子提示，默认无可辨文字群众环境声、无真人口播。环境音分级渐强，最后1秒压低，开跑停止；用户首次交互后播放。新增氛围音缺失只登记warning，不关闭玩法；必需美术/config缺失维持Loading错误门。资源预加载，换场/销毁清理反馈和循环音。
