750×1334手机设计基准，上方比赛、下方15组合三角倍率表。触摸组合松手后按当前1/5/10分档位押分，长按连押；打开“撤销”后按相同档位减分。在空白格“更多”中切换档位、整套沿用上场、打开设置或帮助；沿用替换本场，不足时原押分不变。独立清空、最近20场历史、开跑/下一场按钮。准备起跑和比赛中倍率表保留并锁定押分。点击右侧“选择赛事”，按本场可用积分选择驿站赛（0）、地区赛（1000）或冠军赛（3000），对应4/8/12类设备（冠军赛含六格动态闸箱）；不收参赛费，下一场重新定档。手动或自动开跑均有3秒准备；冠军赛的大屏转播当前赛场并显示本场冠亚军。桌面仍支持右键每次撤1分、C清空、Enter/空格开跑及下一局；F8+F9添加测试积分。加载完成前不开放比赛。全部为本地虚拟积分。

设置提供总音量、音效、环境音、静音及下场起减少动态。帮助内查看规则与累计里程碑；仅余额和已押都为0且尚未开跑时，可确认以500分开始新旅程，保留设置和累计记录。

支持WebLocks的浏览器会原子保存当前比赛；刷新或离开后台后手动继续，不推进离线时间、不重抽名次或重复返分。同一存档仅一个活跃窗口，无锁能力时明确显示临时不存档。历史明细保留当场组合/倍率/名次及押分、返分和净变化。
